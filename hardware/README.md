# Hardware

This folder is for the KiCad design of the carrier PCB:

- `ATMega-platform.kicad_pro`, `ATMega-platform.kicad_sch`, `ATMega-platform.kicad_pcb`
- `gerber/`: Gerber and drill files used for fabrication
- `bom.csv`: bill of materials with manufacturer part numbers, including the female socket-header strips and the DIP-28 socket
